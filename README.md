# skincare-app

## Importar productos desde JSON
Inventario → **Importar JSON**. Pega un objeto o una lista; se abre el formulario ya llenado
(sin foto), revisas, subes la foto y das Guardar. Campos:

`name, category, skin[], mlVal, mlUnit, price, priceMayoreo, cost, stock, description[], isKorean, isMini`

`description`: una línea por idea; usa `Título: detalle` para que la tarjeta ponga título y texto debajo.

## Descargas de imágenes
- Icono ⬇ junto a cada producto del Inventario: tarjeta (menudeo/mayoreo/ambos) o solo la foto.
- Catálogo → Exportar imágenes (.zip): todas las tarjetas en stock, o solo las fotos originales.
